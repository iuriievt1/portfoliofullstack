Velora Market Mobile
Mobile marketplace application for Czechia built with React Native, Expo Router and TypeScript.
Buyer marketplace app with Czech interface and scalable architecture prepared for future real backend integrations.

Main categories: fashion, accessories, beauty, home decor, gifts, electronics, premium electronics, food and supplements.
Tech stack: React Native, Expo, TypeScript, Expo Router, Zustand, TanStack Query, React Hook Form, Zod, Jest.
Main screens: Home, Catalog, Search, Product page, Cart, Checkout, Orders, Profile, Addresses, Notifications, Support, Settings, Authentication.

Install:
npm install
npm start
Run iOS:
npm run ios
Run Android:
npm run android
